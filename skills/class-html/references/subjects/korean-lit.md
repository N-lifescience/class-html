# 국어

| PPT | HTML |
|---|---|
| 시어·표현법 설명 | `.sort`(표현법별로 시어 분류), `.quiz[data-multi]`(해당하는 시어 모두 고르기) |
| 지문 + 핵심어 | `mark`, `.blank` |
| 인물 관계, 사건 전개 | `.reveal`(단계마다 관계·사건 공개), `ol.order` |
| 정서 변화 | `.reveal` 칸마다 정서 설명, 또는 `figure.plot`의 점(`data-point`) |
| 고쳐 쓰기 전후 | `.switch`(전/후) |

# 영어·제2외국어·한문

| PPT | HTML |
|---|---|
| 어순 배열 | `ol.order`(정답 순서로 단어·구) |
| 품사·문장 성분 | `.sort` |
| 어휘 확인 | `.quiz`, `.blank` |
| 끊어 읽기 | `.reveal`(칸마다 `/` 표시가 늘어난 문장) |
| 한문 현토·해석 | `.switch`(원문/현토/해석) |

- 외국어 문장에는 `lang` 속성(`<span lang="en">`)을 단다.
- 발음 듣기, 루비 토글, 획순은 아직 엔진 부품이 없다(M3 예정). 후리가나는 `<ruby>`로 쓸 수 있다.
